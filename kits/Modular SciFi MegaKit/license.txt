built against this kit have somewhere to load it from. It is not a distribution
channel for the kit, and it is not the copy you should be building on.

If you want these models, get them from the author:

    https://quaternius.com/packs/modularscifimegakit.html

What is in this folder
----------------------

The glTF export of the pack, laid out as the author ships it:

    Aliens/  Columns/  Decals/  Platforms/  Props/  Walls/
        the modules, one .gltf + .bin per module
    T_*.png
        the ~17 shared texture atlases, at the kit root

Every module references the atlases by **bare filename** (`T_Name.png`), as if
they sat beside the .gltf, so a loader has to know the convention: an image
named here at the kit root is resolved from the kit root, not from the module's
own folder. glTF forbids a URI from leaving its directory, so `../T_Name.png`
is not an option and the rule has to live in the loader.
